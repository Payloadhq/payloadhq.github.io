Agent Payments & Commerce Infrastructure

Software that lets AI agents and APIs charge, get paid, and operate under payment controls: x402 payment flows, per-call API monetization, and MCP tool payments.

About this category

The problems it addresses

Software in this category lets AI agents and APIs charge, get paid, and operate under explicit payment controls. It covers the x402 payment flow end to end: quoting a price, verifying payment on-chain, governing what an agent may spend, and diagnosing the payments that fail.

The products here solve different parts of that flow. A developer charging per API call, a team giving an autonomous agent a spending budget, and an operator debugging a failed settlement are all working in agent payments, but they need different tools.

Common problems

Sound familiar?

  • Charging AI agents per API call or per tool call, in USDC, without building payment infrastructure first
  • Giving autonomous agents spending limits, policy checks, and exactly-once execution before money moves
  • Finding out why an x402 payment failed and what to do next, from real evidence

Choosing well

Buying guidance

Start with the problem closest to yours. If you are building a paid API or MCP server, begin with a toolkit. If agents already spend on your behalf, look at governance first. If payments are failing today, start with diagnostics: they are free locally and quote before anything paid runs.

RevRule API Reference

RevRule is a programmable revenue rules engine: post economic events, and it computes who earns what, writes the ledger, and accrues settlement. Base URL https://payload-rail.fly.dev. Auth: Authorization: Bearer YOUR_API_KEY.

Machine-readable

OpenAPI 3.1: payload-rail.fly.dev/openapi.json — 17 paths, import into Postman, Insomnia, or generate a client.

LLM docs: payload-rail.fly.dev/llms.txt — the whole API in one plain-text file for agents and coding assistants.

x402 manifest: /.well-known/x402 — machine payment metadata for the paid endpoints.

Core endpoints

Graphs

POST /v1/graphs — create a Revenue Graph (name + rules).
GET /v1/graphs/{id} — fetch a graph.
POST /v1/graphs/{id}/activate — activate a graph for production events.

Events & entitlements

POST /v1/graphs/{id}/events — post an economic event (eventId, type, amountMicros, currency). Idempotent on eventId: replays return the original result.
POST /v1/graphs/{id}/simulate — dry-run an event, see entitlements without writing the ledger.
GET /v1/graphs/{id}/ledger — read ledger entries for a graph.

Crypto

GET /v1/crypto/config — accepted assets and receiving address.
POST /v1/crypto/purchase — buy a $99 RevRule license with USDC on Base.
POST /v1/crypto/fees/settle — settle accrued fees on-chain.
GET /v1/fees/balance — accrued fee balances.

x402 machine commerce

POST /v1/x402/event — pay-per-call event endpoint (402 + payment requirements when unpaid).
GET /v1/x402/public/evaluate — free public evaluation entry point.

Quickstart

# 1. Get an API key (free sandbox in the console)
#    https://payload-rail.fly.dev/revrule-console/

# 2. Create a graph
curl -X POST https://payload-rail.fly.dev/v1/graphs \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"marketplace-v1","rules":[{"type":"percentage","splits":[{"to":"platform","pct":10},{"to":"seller","pct":90}]}]}'

# 3. Post an event (amounts in micro-units: 1_000_000 = 1.00)
curl -X POST https://payload-rail.fly.dev/v1/graphs/GRAPH_ID/events \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"event":{"eventId":"sale-1","type":"revenue","amountMicros":"25000000","currency":"USD"}}'

# 4. Read the ledger
curl https://payload-rail.fly.dev/v1/graphs/GRAPH_ID/ledger \
  -H "Authorization: Bearer $KEY"

Try it without writing code

Postman: fork the Payload public workspace — the RevRule collection runs the whole quickstart with one click per request.

CSV import: npx revrule-csv-import revenue.csv --graph GRAPH_ID --api-key $KEY --dry-run — turn a Stripe export or payout CSV into events. GitHub.

Console: revrule-console — visual sandbox, free, no credit card.

Rules of the road

RevRule computes entitlements; it never moves money. Amounts are integers in micro-units (6 decimals). Events are idempotent on eventId. The sandbox is free for evaluation; production Revenue Graphs need the $99 one-time license.

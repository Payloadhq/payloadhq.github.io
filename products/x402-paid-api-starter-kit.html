Veyline Developer Primer

Charge AI agents per API call in USDC, using the x402 payment flow.

The problem it solves

APIs serving AI agents have no native way to charge per call. Bolting on accounts, API keys, and monthly billing does not fit machine customers that need to pay per request, in the request itself.

Who it is for

Developers monetizing an HTTP API used by AI agents or automated clients.

What it does

  • Express middleware that issues HTTP 402 challenges and verifies x402 payments before the route runs
  • Append-only usage ledger recording who paid for what
  • Non-custodial design: payments settle to your own wallet; the middleware never holds funds

Platforms and inputs

Platforms: Node.js 18+, Express

Works with: HTTP API routes in an Express application

Version: 1.0.1

Questions

Does the Primer custody payments?

No. It verifies x402 payments that settle to your own wallet. It is non-custodial and never holds funds.

What do I need to run it?

A Node.js 18+ Express application. You add the middleware to the routes you want to charge for.

MCP Monetization Engine

Per-tool-call payments for MCP servers, with free quotas and a usage ledger.

The problem it solves

MCP servers give their tools away by default. There is no built-in way to charge per tool call, grant a free quota, or show a client machine-readable payment requirements before a call runs.

Who it is for

Builders of MCP servers who want paid tools alongside free ones.

What it does

  • Paid tool registry: mark individual tools as paid, with per-tool pricing
  • Free quotas so clients can evaluate before paying
  • Machine-readable payment requirements a client can act on before calling
  • Usage ledger of paid and free calls, plus an adapter for the official MCP SDK

Platforms and inputs

Platforms: Node.js 18+, Official MCP SDK

Works with: MCP tool calls via the official @modelcontextprotocol/sdk Server

Version: 1.0.1

Questions

Which MCP SDK does it work with?

It adapts to the official @modelcontextprotocol/sdk Server in Node.js 18+.

Can some tools stay free?

Yes. The registry supports free quotas per tool, so evaluation calls can stay free while production calls are paid.

StableLedger

Offline CLI that turns stablecoin exchange CSV exports into clean realized profit and loss records, fees included.

The problem it solves

Exchange CSV exports are inconsistent and fee handling is scattered across rows, so building a clean record of stablecoin activity by hand is slow and error-prone.

Who it is for

Freelancers and small businesses organizing stablecoin transaction records.

What it does

  • Zero-dependency Python CLI: runs offline, nothing uploaded
  • Organizes stablecoin transaction CSV exports into clean realized profit/loss records with fees accounted for
  • Tested against Kraken-format export files
  • Data-organization software: it prepares records; it is not tax advice and does not file anything

Platforms and inputs

Platforms: Python 3

Works with: Exchange CSV exports (tested against Kraken-format files)

Version: 1.0.0

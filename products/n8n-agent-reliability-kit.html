n8n Reliability Guard

Production-readiness for n8n AI agents: guardrail templates, a failure-simulation eval harness, and a readiness score.

The problem it solves

n8n AI agents fail in production in documented, repeatable ways: timeouts, malformed tool output, runaway loops, silent partial failures. Most workflows ship with no guardrails and no way to test failure behavior before users depend on them.

Who it is for

Builders running AI agents in n8n for real work.

What it does

  • 10 importable n8n workflow templates covering documented agent failure classes
  • Node.js failure-simulation eval harness with readiness scoring, run against a model of your agent
  • 37-page production playbook covering the failure classes, the guardrails, and the scoring

Platforms and inputs

Platforms: n8n, Node.js 18+ (eval harness)

Works with: n8n workflows; the eval harness tests a JavaScript model of your agent written from the documented shape

Version: 1.0.1

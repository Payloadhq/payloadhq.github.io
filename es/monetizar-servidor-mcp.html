Monetiza tu servidor MCP

Cobra por llamada de herramienta en tu servidor MCP: registro de herramientas de pago, cuotas gratuitas y un libro de uso, con requisitos de pago legibles por máquina y adaptador para el SDK oficial de MCP.

¿Prefieres inglés? Read the English product page. Prefere português? Leia a página em português.

El problema

Construiste un servidor MCP que resuelve un problema real, y hoy cualquiera puede llamar a tus mejores herramientas gratis. Cobrar por llamada parece sencillo hasta que aparece la lista de piezas: requisitos de pago que el cliente pueda leer, verificación antes de liberar la llamada, cuotas gratuitas por cliente y un registro confiable de quién llamó a qué. Construir esa capa desde cero lleva semanas que no van a tu producto.

Cómo funciona

Declaras el precio de cada herramienta en un registro. Cuando un cliente llama a una herramienta de pago más allá de la cuota gratuita, el servidor responde 402 con los requisitos de pago en un formato legible por máquina (el protocolo x402). El cliente paga, la llamada se verifica y se libera, y cada llamada queda anotada en el libro de uso.

Qué incluye

  • Registro de herramientas de pago con precio por llamada.
  • Cuotas gratuitas por herramienta y por cliente.
  • Requisitos de pago legibles por máquina (x402).
  • Libro de uso de todas las llamadas.
  • Adaptador para el SDK oficial de MCP.
  • Node.js 18+, versión 1.0.1.

Preguntas frecuentes

¿En qué entorno funciona?

Node.js 18 o superior, con el SDK oficial de MCP. El kit incluye un adaptador para el SDK, un registro de herramientas de pago, cuotas gratuitas por herramienta y el libro de uso.

¿Cómo pagan los usuarios por las llamadas?

Mediante el protocolo x402: el servidor responde 402 con requisitos de pago legibles por máquina, el cliente paga en USDC y la llamada se libera tras la verificación. Tú defines el precio de cada herramienta y cuántas llamadas gratuitas tiene cada cliente al día.

¿Cómo recibo el producto tras la compra?

El pago se procesa con Stripe. Al completar la compra, la página de confirmación muestra tu clave de descarga una sola vez; con ella descargas el kit en esta misma página. Guarda la clave.

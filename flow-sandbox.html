Flow Sandbox — program the economics, watch the money move

This page runs the actual Payload Flow revenue engine in your browser, the same code that processed real money during acceptance testing. Pick a scenario, run a revenue event, and watch every micro-unit get assigned, explained, and recorded. Nothing here moves money. Every distribution the engine produces is a proposal, never an execution.

Proof this engine handles real money. It processed a $1.00 Stripe charge, two 0.10 USDC settlements on Base Sepolia (tx 1, tx 2), and a $1,000 royalty statement, with every split verified to the micro-unit. Sandbox runs below are simulated.

What you are looking at

  • Entitlements are computed by rules, evaluated in priority order against the pool. The reason column shows the engine's own explanation for each line.
  • Payload fee is the infrastructure fee the engine computes per event. In the sandbox it uses the builder license rate so the line is visible.
  • Conservation is structural: entitlements plus fees always equal the pool, because the remainder rule absorbs whatever is left. The check below each run proves it.
  • Ledger entries are hash chained. Each entry links the event to the graph version and the rule that produced it.
  • The recoupment scenario is stateful: run it six times and watch the $5,000 advance finish recouping before the splits begin.

Payload Flow observes economic events, computes who is owed what, and proposes payout instructions. Regulated partners move the money. The engine never holds funds and never controls settlement. Full source: github.com/Payloadhq/payload-flow.

Monetize seu servidor MCP

Cobre por chamada de ferramenta no seu servidor MCP: registro de ferramentas pagas, cotas gratuitas e um livro-razão de uso, com requisitos de pagamento legíveis por máquina e adaptador para o SDK oficial do MCP.

O problema

Você construiu um servidor MCP que resolve um problema real, e hoje qualquer pessoa pode chamar suas melhores ferramentas de graça. Cobrar por chamada parece simples até a lista de peças aparecer: requisitos de pagamento que o cliente consiga ler, verificação antes de liberar a chamada, cotas gratuitas por cliente, e um registro confiável de quem chamou o quê. Construir essa camada do zero leva semanas que não vão para o produto.

Como funciona

Você declara o preço de cada ferramenta em um registro. Quando um cliente chama uma ferramenta paga além da cota gratuita, o servidor responde 402 com os requisitos de pagamento em formato legível por máquina (o protocolo x402). O cliente paga, a chamada é verificada e liberada, e cada chamada entra no livro-razão de uso.

tools: { "deep_research": { price: "$0.05/call", quota: "3 free / day" }, "summarize": { price: "free" } }

  • Registro de ferramentas pagas com preço por chamada.

  • Livro-razão de uso de todas as chamadas.
  • Adaptador para o SDK oficial do MCP.

Perguntas frequentes

Em que ambiente ele roda?

Node.js 18 ou superior, com o SDK oficial do MCP. O kit inclui um adaptador para o SDK, um registro de ferramentas pagas, cotas gratuitas por ferramenta e o livro-razão de uso.

Como os meus usuários pagam pelas chamadas?

Pelo protocolo x402: o servidor responde 402 com requisitos de pagamento legíveis por máquina, o cliente paga em USDC e a chamada é liberada após a verificação. Você define o preço de cada ferramenta e quantas chamadas gratuitas cada cliente tem por dia.

Como recebo o produto depois da compra?

O checkout é feito pela Stripe. Ao concluir o pagamento, a página de confirmação mostra a sua chave de download uma única vez; com ela, você baixa o kit nesta mesma página. Guarde a chave.

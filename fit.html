When Payload is (and isn't) the right fit

Every tool below is a local utility with a one-time purchase and a single-seat perpetual license. These pages exist so you can disqualify us quickly — a tool that is wrong for your job is wrong even if it is ours.

Appropriate for

x402 Paid API Starter Kit — $79

  • You run an Express/Node.js API and want AI agents to pay per call in USDC via the x402 flow.
  • You want a verifiable starting point: 402 challenges, facilitator verification, JSONL ledger, manifest endpoint, 9/9 passing end-to-end tests.
  • You are comfortable supplying your own x402 facilitator and recipient wallet address.

MCP Monetization Kit — $69

  • You operate an MCP server on the official MCP SDK and want per-tool-call payments with free quotas for some tools.
  • You want the metering mechanic demonstrated over stdio with a real SDK client, then wired into your own server.

StableLedger — $49

  • You have stablecoin transaction CSV exports (tested against Kraken-format files) and want them organized into clean realized P/L records with fees.
  • You want fully offline, zero-dependency recordkeeping in Python 3.

AI Search Readiness Audit — $59

  • You want a one-click technical audit of the page you are viewing: raw-HTML coverage, AI Overviews eligibility, AI-crawler robots.txt matrix, dead schema detection.
  • You want the measurement to run 100% client-side with no account, no server, and no tracking.

CRM Dedup & Migration Cleanup Kit — $149

  • You are migrating a CRM and need to deduplicate a CSV export offline before import.
  • You want normalization, fuzzy matching with confidence tiers, dry-run merge plans, and machine-readable change logs (JSON + CSV).
  • You can review low-confidence matches yourself rather than auto-merging everything.

n8n Production AI Agent Reliability Kit — $99

  • You run AI agents in n8n and want to test the documented failure classes (timeouts, empty results, malformed output, rate limits, runaway loops) before production.
  • You can write a JavaScript model of your agent from the documented shape for the eval harness to test.

MCP Launch Readiness Audit — $79

  • You are about to launch an MCP server and want a 48-rule audit (tool poisoning, hardcoded credentials, server exposure, over-privileged tools, SSRF, missing auth/hardening) with a concrete remediation for every finding.
  • You want hardened templates, a stress-test harness, and a CI workflow alongside the scanner.

x402 + MCP Bundle — $119

  • You need both kits above — per-API-call payments and per-MCP-tool-call payments — and want them at one bundle price.

Not appropriate for

  • Managed services. These are local utilities, not SaaS. There is no hosted dashboard, no managed API, no uptime SLA, no multi-user collaboration.
  • Investment, trading, or tax advice. StableLedger organizes transaction records; it does not calculate taxes, does not give tax advice, and is not a financial product. The x402 kit verifies payments; it never holds keys or funds and never executes trades.
  • Live CRM APIs. The CRM kit works on CSV exports, not live connections to HubSpot, Salesforce, or other CRMs.
  • Live n8n instances. The n8n eval harness tests a JavaScript model of your agent that you write; it does not connect to a live n8n instance. Token-cost figures are simulated estimates.
  • Certifications or penetration tests. The MCP Launch Readiness Audit is an audit, not a certification, and cannot prove the absence of vulnerabilities. It is not penetration testing.
  • Guaranteed AI citations. The AI Search Readiness Audit reports what your page declares — measurements, not predictions. It cannot make an AI system cite your content.
  • Non-Express stacks for x402. The x402 kit is Express/Node-focused; it is not a generic payment gateway for other frameworks.
  • Subscription buyers. Every product is a one-time purchase with a single-seat perpetual license. If you need recurring delivery or managed hosting, these tools are the wrong choice.

If none of the above applies to your situation, the honest move is to not buy. The free utilities and open-source projects stay free regardless.

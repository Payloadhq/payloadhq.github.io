Docs & GitHub

Everything public lives under github.com/Payloadhq. Free projects are MIT-licensed; product repos carry documentation and links to the paid kits.

Free & open source

payload-sample-mcp-server

Free sample MCP server on the official MCP Python SDK demonstrating per-tool-call x402 payments: unpaid callers get machine-readable payment requirements, paying callers get results, free tools stay free. Companion to the MCP Monetization Kit.

MIT Python MCP

mcp-monetization-demo

Runnable demo of the metering mechanic behind the MCP Monetization Kit: per-tool-call metering with a free quota, then machine-readable PAYMENT REQUIRED. Stdlib Python only, hard-capped so it can't replace the paid kit.

MIT Python

n8n-reliability-free-samples

Two production n8n workflows from the Reliability Kit (failure-alert dispatcher, HTTP timeout circuit breaker), import-ready with zero credentials required.

MIT n8n

mcp-manifest-validator

Validate an MCP server.json manifest before you publish: required fields, name format, semver, transport declarations, and the common mistakes registries reject. Zero dependencies.

MIT Python MCP

n8n-workflow-linter

Static lint for exported n8n workflow JSON: missing error handling, HTTP nodes without timeouts or retries, hardcoded secrets, trigger problems, dead nodes. Each finding names the node and the fix.

MIT Python n8n

csv-duplicate-inspector

Inspect a CSV for duplicate risk before a migration: exact-duplicate rows, key-column duplicates, near-duplicates. Streams large files instead of loading them.

MIT Python CSV

mcp-readiness-check

Free GitHub Action: 10 MCP server readiness checks on every pull request — manifest validity, name format, semver, transport, secret heuristics. Use Payloadhq/mcp-readiness-check@v1.

MIT GitHub Action MCP
